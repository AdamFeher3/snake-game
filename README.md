<h1><a href="https://adamfeher3.github.io/snake-game/">Snake Game</a></h1>
<p>A simple <b>Snake game</b> built with HTML, CSS and JavaScript</p>
<h2>How to play</h2>
<p>
  Use <b>WASD</b> or <b>Arrow Keys</b> to control the snake<br>
  Press <b>P</b> or <b>ESC</b> to pause/resume the game
</p>
